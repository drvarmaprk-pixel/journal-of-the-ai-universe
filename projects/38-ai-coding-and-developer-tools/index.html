Coding agents are moving into security and customisation. GitHub made agentic autofix and AI Scan for pull requests generally available, Copilot CLI added agent hooks, and Claude Code became moddable.

Top updates

  • Agentic autofix for code scanning alerts is GA, GitHub · 15 Oct 2026: An agent now drafts fixes for code-scanning alerts.
  • AI Scan for pull requests is GA, GitHub · 15 Oct 2026: AI security review on pull requests, covering PHP, Shell, Terraform HCL, Dockerfiles and more.
  • Copilot CLI v1.0.97, GitHub · 13 Oct 2026: Adds agent-scoped declarative hooks.
  • Claude Code becomes moddable, XDA · 13 Oct 2026: 'Mods' — TypeScript functions that customise Claude Code — were announced on 1 Oct.

Research
